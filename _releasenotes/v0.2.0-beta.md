# v0.2.0-beta

## Multi-LLM Provider Support & UI Overhaul

Burnrate now tracks usage across multiple LLM coding tools — Claude, Codex, Kimi K2.5, and Gemini CLI. The popover has been completely redesigned with a summary dashboard, collapsible detail sections, official brand icons, and smarter reset time displays.

### New Features

- **Usage summary dashboard** — Quick-glance overview at the top of the popover showing all providers side by side. Each row displays a provider icon, name, and mini progress bar with percentage. Providers without data show contextual status: "Coming soon" (installed, tracking not yet supported), "No data" (installed, no recent usage), or "Not found" (CLI not detected).

- **Collapsible provider sections** — Each provider's detail view is now expandable/collapsible. Tap anywhere on the header row to toggle. A rotating chevron indicates state. All sections start collapsed by default. Expansion preferences persist across app restarts.

- **Official brand icons** — Each provider displays its actual brand mark (Claude spark, OpenAI hexagonal knot, Kimi K letterform, Gemini sparkle). SVG logos are embedded as template images that adopt the provider's brand color and adapt to light/dark mode.

- **Kimi K2.5 & Gemini CLI support** — Both providers detect their CLI installations (`~/.kimi` and `~/.gemini`). When installed, they show "Installed — usage tracking coming soon". When not installed, they display the provider's install command (selectable text for easy copying). Kimi respects the `KIMI_SHARE_DIR` environment variable. Usage parsing will be added as these CLIs expose rate-limit data locally.

- **New cycle start alerts** — Get notified when a 5-hour or 7-day usage cycle resets. Detects when utilization drops significantly between refreshes. Enable/disable via the "New cycle alerts" toggle in Settings > Alerts.

- **Dual reset time display** — Progress bars now show both a countdown and the local clock time, e.g. "Resets in 2h 30m (3:45 PM)". Formats smartly: just the time for today, "Tomorrow 8:00 AM" for next day, "Wed 3:00 PM" for further out.

- **Install commands in not-installed views** — When a CLI tool isn't detected, the detail view shows an actionable install command in monospace text that can be selected and copied.

### Changed

- **Popover layout** — Removed the binary Claude/Codex segmented tab picker. New layout from top to bottom: summary overview, expandable provider cards (Claude, Codex, Kimi, Gemini), recent sessions. The active Claude session card moved inside Claude's expandable section.

- **Menubar source selection** — Settings now offers all four providers (Claude, Codex, Kimi K2.5, Gemini) as the menubar data source, each with its brand icon and color.

- **Provider architecture** — New `LLMProvider` protocol and `ProviderUsage` / `ProviderInfo` models unify how all providers expose their data. Adding a new LLM requires one small file conforming to the protocol.

### Fixed

- **Expand/collapse animation** — Content no longer flies in from the top when expanding a section. Replaced slide transition with a clean opacity fade.

- **Expand/collapse click area** — The entire header row is now clickable, not just the chevron or title text. Added vertical padding and `contentShape(Rectangle())` for a comfortable hit target.

### Known Issues

- **Auto-update prompts for App Management permission (macOS 13+)** — The first time you update via Sparkle, macOS may show an "Update Error" and prompt you to allow App Management. This is a one-time macOS permission requirement, not a bug. To resolve: go to **System Settings > Privacy & Security > App Management**, enable Burnrate, then try **Check for Updates** again. Subsequent updates will work without prompting.
